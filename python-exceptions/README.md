# Python - Exceptions

This directory contains projects on Python exception handling
(`try` / `except` / `finally` and `raise`).

| File | Description |
| ---- | ----------- |
| `0-safe_print_list.py` | Prints x elements of a list and returns how many were printed. |
| `1-safe_print_integer.py` | Prints an integer with `"{:d}".format()`; returns True or False. |
| `2-safe_print_list_integers.py` | Prints the first x elements of a list, only integers. |
| `3-safe_print_division.py` | Divides 2 integers and prints the result in `finally`. |
| `4-list_division.py` | Divides 2 lists element by element, handling errors. |
| `5-raise_exception.py` | Raises a `TypeError`. |
| `6-raise_exception_msg.py` | Raises a `NameError` with a message. |
