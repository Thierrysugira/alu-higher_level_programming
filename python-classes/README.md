# Python - Classes and Objects

This directory contains projects on Python classes: private attributes,
properties (getters/setters), validation and printing.

| File | Description |
| ---- | ----------- |
| `0-square.py` | An empty class `Square`. |
| `1-square.py` | `Square` with a private `size` attribute. |
| `2-square.py` | `Square` with `size` type and value validation. |
| `3-square.py` | Adds the `area` method. |
| `4-square.py` | Adds a `size` property with getter and setter. |
| `5-square.py` | Adds `my_print` to print the square with `#`. |
| `6-square.py` | Adds a validated `position` property used by `my_print`. |
| `100-singly_linked_list.py` | `Node` and `SinglyLinkedList` with `sorted_insert`. |
| `101-square.py` | `Square` printable with `print()`. |
| `102-square.py` | `Square` comparable by area (`==`, `!=`, `<`, `<=`, `>`, `>=`). |
| `103-magic_class.py` | `MagicClass` rebuilt from Python bytecode. |
