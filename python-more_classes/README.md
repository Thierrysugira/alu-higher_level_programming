# Python - More Classes and Objects

This directory contains projects on Python classes: class attributes,
static and class methods, `__str__`, `__repr__` and `__del__`.

| File | Description |
| ---- | ----------- |
| `0-rectangle.py` | An empty class `Rectangle`. |
| `1-rectangle.py` | `Rectangle` with validated `width` and `height` properties. |
| `2-rectangle.py` | Adds `area` and `perimeter` methods. |
| `3-rectangle.py` | Adds a string representation made of `#`. |
| `4-rectangle.py` | Adds a `repr` that can be used with `eval()`. |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted. |
| `6-rectangle.py` | Adds the `number_of_instances` class attribute. |
| `7-rectangle.py` | Adds the `print_symbol` class attribute. |
| `8-rectangle.py` | Adds the `bigger_or_equal` static method. |
| `9-rectangle.py` | Adds the `square` class method. |
| `101-nqueens.py` | Solves the N queens puzzle with backtracking. |
