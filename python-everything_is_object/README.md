# Python - Everything is object

This directory contains projects on Python objects: `id()` and `type()`,
mutable and immutable objects, aliasing, and how arguments are passed
to functions.

Files `0-answer.txt` to `28-answer.txt` hold the answers to the quiz
tasks, and `19-copy_list.py` returns a copy of a list.

Advanced tasks: `100-magic_string.py` (a function that grows its output on
each call), `101-locked_class.py` (restricts new instance attributes) and
the `103` to `106` answer files about how many `int` and `str` objects are
created by CPython.
