The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

MyList is a subclass of list:

    >>> issubclass(MyList, list)
    True

An empty list prints an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Elements added with append are sorted when printed:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is not modified:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

A list that is already sorted:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

A list sorted in reverse order:

    >>> my_list = MyList([5, 4, 3, 2, 1])
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Negative numbers:

    >>> my_list = MyList([3, -1, 0, -7, 2])
    >>> my_list.print_sorted()
    [-7, -1, 0, 2, 3]

Duplicated numbers:

    >>> my_list = MyList([2, 3, 2, 1, 3])
    >>> my_list.print_sorted()
    [1, 2, 2, 3, 3]

A list with one element:

    >>> my_list = MyList([42])
    >>> my_list.print_sorted()
    [42]

Large numbers:

    >>> my_list = MyList([10 ** 12, 5, -10 ** 12])
    >>> my_list.print_sorted()
    [-1000000000000, 5, 1000000000000]

The list keeps working like a normal list after sorting:

    >>> my_list = MyList([3, 1, 2])
    >>> my_list.print_sorted()
    [1, 2, 3]
    >>> my_list.append(0)
    >>> print(my_list)
    [3, 1, 2, 0]
    >>> my_list.print_sorted()
    [0, 1, 2, 3]
    >>> len(my_list)
    4

Calling the method on the class without an instance fails:

    >>> MyList.print_sorted()  # doctest: +ELLIPSIS
    Traceback (most recent call last):
    ...
    TypeError: ...print_sorted() missing 1 required positional argument: 'self'
