# Python - Input/Output

This directory contains projects on file handling and JSON: reading,
writing and appending files with `with`, JSON serialization and
deserialization, and class-to-dictionary conversion.

| File | Description |
| ---- | ----------- |
| `0-read_file.py` | Reads a text file and prints it to stdout. |
| `1-write_file.py` | Writes a string to a text file. |
| `2-append_write.py` | Appends a string to a text file. |
| `3-to_json_string.py` | Returns the JSON string of an object. |
| `4-from_json_string.py` | Returns an object from a JSON string. |
| `5-save_to_json_file.py` | Writes an object to a file as JSON. |
| `6-load_from_json_file.py` | Creates an object from a JSON file. |
| `7-add_item.py` | Adds arguments to a list saved in `add_item.json`. |
| `8-class_to_json.py` | Returns the dictionary description of an object. |
| `8-my_class.py`, `8-my_class_2.py` | Example classes used to test task 8. |
| `9-student.py` | `Student` with a `to_json` method. |
| `10-student.py` | `to_json` with an attribute filter. |
| `11-student.py` | Adds `reload_from_json`. |
| `12-pascal_triangle.py` | Returns Pascal's triangle of n. |
| `100-append_after.py` | Inserts a line after each line containing a string. |
| `101-stats.py` | Reads an HTTP log from stdin and prints metrics every 10 lines. |
